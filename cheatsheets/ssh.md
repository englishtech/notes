# SSH: Подключение по ключам

SSH — защищенный доступ.  
Ключи — пара файлов (приватный + публичный).  
Приватный: Секрет, хранится у тебя.  
Публичный: Копируется на сервер.  
Папки: Локально `~/.ssh/`, на сервере `~/.ssh/authorized_keys`.  

---

**1. Создать ключ (локально):**  
`ssh-keygen -t ed25519 -f ~/.ssh/vps_key -C "comment"` (Жать Enter, пароль пустой)  

**2. Загрузить публичный ключ (на сервер):**  
`ssh-copy-id -i ~/.ssh/vps_key.pub user@ip_server`  
*(Вручную: скопировать текст `.pub` → сервер `nano ~/.ssh/authorized_keys`)*  

**3. Подключиться:**  
`ssh -i ~/.ssh/vps_key user@ip_server`  

---

**⚠️ Нюансы:**  
**Права:** На сервере `chmod 700 ~/.ssh`, `chmod 600 ~/.ssh/authorized_keys`.  
**Кириллица:** Если путь с русскими буквами, добавь `-o UserKnownHostsFile=/path`.  
**Config:** Чтобы не писать `-i`, создать `~/.ssh/config` (Host, IdentityFile).  
**Ошибка:** `Permission denied` → проверить права файлов и совпадение ключей.  
**Безопасность:** Приватный ключ никому не передавать. **Проверка:** Если не спрашивает пароль — всё ок.**
